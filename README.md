# 📚 Trilha de Estudos & Roteiros Práticos de Programação

Repositório centralizado de **roteiros lógicos, guias de estudo, desafios de código e boas práticas** para desenvolvimento de software. Criado para estruturar o aprendizado prático passo a passo, desde os fundamentos até a preparação para entrevistas técnicas.

---

## 🎯 Objetivo do Repositório

Em vez de apenas ler teorias ou copiar soluções prontas, o foco deste repositório é fornecer **roteiros direcionados de implementação**. Cada guia traz exercícios graduais (do fácil ao avançado), indicando o que construir, quais restrições seguir e como validar a solução.

## 🧭 Metodologia Recomendada de Estudo

Para tirar o máximo proveito dos roteiros:

1. **Pense antes do código:** Leia o roteiro e tente esboçar a solução em papel, bloco de notas ou pseudocódigo.
2. **Implemente de forma independente:** Evite olhar códigos prontos ou respostas de IA imediatamente. Enfrente a trava lógica antes de buscar ajuda.
3. **Teste cenários limite (*edge cases*):**
   - Entradas vazias (`[]`, `""`, `None`/`null`)
   - Valores negativos ou extremos
   - Estruturas já ordenadas ou invertidas
4. **Avalie a eficiência:** Analise o consumo de tempo e memória da sua solução (notação Big O).
5. **Pratique repetição espaçada:** Revisite exercícios mais difíceis dias depois, reconstruindo a solução do zero.

   - Para configurar um bom ambiente de desenvolvimento: consulte o [guia-extensoes-vscode.md](guia-extensoes-vscode.md).
